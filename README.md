# Dion Pratama Portfolio

Standalone HTML/CSS/JS rebuild based on the exported Emergent portfolio.

## Files
- `index.html` — semantic page structure
- `style.css` — cleaned design system + responsive layout
- `script.js` — navigation, scroll reveal, project modal, mobile menu
- `assets/` — folder reserved for self-hosted images

## Assets
The exported HTML did **not** contain image binaries; it contained references to Unsplash image IDs. This rebuild keeps those images as direct Unsplash URLs so it works immediately. To make it fully local/offline, download the five referenced images and put them in `assets/`, then replace the URLs in `index.html` and `script.js`.

## Run
Open `index.html` or use VS Code Live Server.
